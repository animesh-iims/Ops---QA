One-time setup inside the telecallers' working Google Sheet
  1. Open the Google Sheet the telecallers work in. Add a new tab named exactly System_Logs.
  2. In row 1 of that tab, add headers: Timestamp, Farm ID, Telecaller Name, User Email, Edited Field, New Value.
  3. Go to Extensions > Apps Script, delete any existing code, and paste the downloaded script.
  4. In the script, set FARM_ID_COL and TELECALLER_COL to match your actual sheet's column numbers (A=1, B=2, C=3...), and confirm the working tab is named Live_Queue or edit that check to match your tab name.
  5. Save, then edit any cell on the working tab to confirm a row appears on System_Logs.
  6. Right-click the System_Logs tab, choose Hide sheet, and restrict edit access to managers only, so raw activity data can't be accidentally cleared.
!This captures saved edits, not raw clicks. Google Sheets has no API for cell-focus events, so "time from click to save" isn't something any external tool can observe. This is the closest precise proxy available: time between the first and last edit recorded against a Farm ID.
